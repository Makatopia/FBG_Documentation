# Proportions

The Proportions section is where you define the blockout's body build before you pose or animate. It follows the cranial-unit (CU) proportion method used throughout FBG, so body changes stay consistent and predictable.

Two control groups:

- **Structure** — body build and segment relationships (silhouette, limb ratios)
- **Volume** — how full or lean each body area looks (mass distribution)

Think of it as: Structure = build, Volume = mass.
