# Posing

FBG's pose system uses anatomically focused sliders rather than direct bone rotations. Each slider targets a specific anatomical motion and updates the blockout in a consistent, predictable way.

Posing is organized by body section:

- [Spine & Pelvis](spine-pelvis.md) — pelvis position/rotation, torso segments, neck, head
- [Shoulder Girdle](shoulder-girdle.md) — shoulder elevation, protraction, scapula response
- [Arms](arms.md) — FK/IK modes, elbow control, hand pin
- [Legs](legs.md) — FK/IK modes, knee control, valgus, hyperextension
- [Feet](feet.md) — foot roll, bank, ankle, toe controls
- [Hands](hands.md) — finger curl, splay, curl shape, thumb controls
